# Archetype: retail-catalog (fashion / craft / sparepart — product catalog)

## matches

- butik, distro, kerajinan tangan, sparepart, aksesoris
- any retail whose value lives in browsing a product range

## recommended_sections

- Product grid — the catalog is the product; cards with photo + name + price are the headline.
- Price legible on every card — the shopper filters by price before anything else; hide it and they bounce.
- Category filter — only if there are 3+ real categories (e.g. pakaian / aksesoris / sepatu).
- Store info — hours + address + WhatsApp for stock question.

## avoid_sections

- Single hero CTA — "Lihat Produk" as the only entry hides the actual catalog.
- Testimoni carousel — retail trust comes from the products + price, not fabricated quotes.
- About-heavy first fold — the story can live below the grid, not above it.

## page_count

- landing: one page. `marketing_site` only when categories need their own detail page; otherwise a filterable grid wins.

## cta_logic

- Primary: "Lihat katalog" or direct "Beli via WA" on the card. Secondary: per-item stock inquiry CTA when items run out fast (e.g. thrift, limited craft runs).

## visual_hooks

- Card-first layout: equal photo size, price below the photo in body type, not as a badge.
- Category chips above the grid, not a sidebar — works on mobile.
- Neutral product background so the items carry the color, not the page chrome.

## example_structure

Header (name + search/filter) → Category chips → Product grid → Store info (hours + address + WA) → Footer. Depart when justified — a brand-led butik may lead with a lookbook before the grid.
