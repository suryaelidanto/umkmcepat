# Archetype: agri-produce (petani / organik / hasil bumi)

## matches

- petani, kelompok tani, produsen organik, penjual hasil bumi langsung
- any producer whose value is the produce + origin + direct order

## recommended_sections

- Products / produce list — what is grown or harvested, seasonal and current; the produce IS the product, not a story.
- Origin + farm location — where it comes from, named farm + region; "dari kebun di [daerah]" is the trust signal.
- Order / contact CTA — WA or form; the transaction is an order lead, not a cart checkout.
- Seasonal availability — what is in season now vs. soon; freshness gates the buy decision.

## avoid_sections

- Generic 3-feature grid — "Segar, Sehat, Alami" says nothing about the actual produce.
- Long farm-history section — the produce + origin are the signal; the founder's story can live below.
- Fabricated certifications — only show organic/gap labels if real; a fake "Bersertifikat Organik" chip is fraud.

## page_count

- landing: one page. `marketing_site` only when the farm runs distinct lines (e.g. fresh produce vs. processed goods like keripik) each needing a detail page.

## cta_logic

- Primary: "Pesan" via WA with the product pre-filled. Secondary: "Langganan" only when a CSA/subscription box is a real offering.

## visual_hooks

- Produce-forward imagery: a real harvest or farm photo, not a stock vegetable gradient.
- Origin chip ("dari [daerah]") on the product list, not buried in body copy.
- Seasonal badge ("Musim ini" / "Tersedia sekarang") on each product, not a generic "stok terbatas".

## example_structure

Header (farm name + origin chip) → Products / produce list (seasonal badge) → Farm location + origin → Order CTA ("Pesan"). Depart when justified — a kelompok tani may add a bulk-pricing table for resellers before the order CTA.
