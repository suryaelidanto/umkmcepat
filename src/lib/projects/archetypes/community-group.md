# Archetype: community-group (komunitas / paguyuban / arisan)

## matches

- komunitas, paguyuban, arisan, klub hobi, perkumpulan warga
- any group whose value is membership + gathering, not a product

## recommended_sections

- About the group — who it is for and what binds members (interest, neighborhood, profession); the visitor self-selects here.
- Upcoming events / meetups — the next gathering is the headline; a group without a calendar reads as dormant.
- Membership benefits — what joining unlocks (meetups, WA group, shared resources); concrete, not "jejaring luas".
- Join CTA — the path to membership; the transaction is a sign-up, not a checkout.

## avoid_sections

- Generic 3-feature grid — "Belajar, Berkarya, Bersosialisasi" says nothing about this specific group.
- Testimoni carousel — avoid unless real members attribute quotes; a community's signal is its event cadence, not fabricated praise.
- Pricing table — most communities are free or dues-based; a tiered price table reads as a SaaS, not a paguyuban.

## page_count

- landing: one page. `marketing_site` only when the group runs multiple recurring event series (e.g. monthly meetup + annual retreat) each warrant a detail page.

## cta_logic

- Primary: "Gabung" opening the membership path (form or WA). Secondary: "Daftar event" only when an upcoming gathering needs a separate RSVP.

## visual_hooks

- Member-count or next-event badge near the CTA, not buried in body copy — momentum signals belonging.
- Event photos from real meetups, not stock crowd shots — authenticity is the trust signal.
- A roster or member-strip of named members/roles, not anonymous avatars.

## example_structure

Header (name + member count) → About the group → Upcoming events → Membership benefits → Join CTA ("Gabung"). Depart when justified — an arisan may swap the events list for a "jadwal arisan berikutnya" card with date + host.
