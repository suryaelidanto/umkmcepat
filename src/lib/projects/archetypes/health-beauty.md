# Archetype: health-beauty (klinik kecantikan / spa / salon treatment)

## matches

- klinik kecantikan, spa, salon perawatan, barbershop premium, estetika
- any service whose value is a per-service treatment + booking flow

## recommended_sections

- Services menu — the named treatments (e.g. "Facial Hydrating", "Paket Bridal") with duration + price; the menu IS the product.
- Packages / bundled deals — multi-session or combo offers; the buyer compares packages, not single treatments.
- Booking CTA — slot-based booking or WA reservation; the transaction is an appointment, not a checkout.
- Therapist / practitioner credentials — named staff with certifications; trust in a treatment business gates on who handles the service.

## avoid_sections

- Generic 3-feature grid — "Profesional, Higienis, Hasil Optimal" says nothing about the actual treatments.
- Fabricated before/after — avoid unless real, consented client photos exist; faked results read as malpractice.
- Discount banner spam — a single promo is fine; a stack of "90% OFF" chips reads as a marketplace, not a clinic.

## page_count

- landing: one page. `marketing_site` only when treatment lines (e.g. facial vs. slimming vs. bridal) each warrant a detail page.

## cta_logic

- Primary: "Booking" opening the slot picker. Secondary: "Konsultasi via WA" only when a treatment needs skin/scalp assessment before booking.

## visual_hooks

- Treatment-forward imagery: a real treatment-room photo or a service-in-progress shot, not a stock spa gradient.
- Price + duration legible on every service card, not hidden behind a WA inquiry.
- Practitioner cards with credential tags, not anonymous "tim profesional".

## example_structure

Header (name + next-slot badge) → Services menu (cards: treatment + duration + price) → Packages → Practitioners → Booking CTA. Depart when justified — a bridal package may lead with a "Paket Bridal" hero before the general menu.
