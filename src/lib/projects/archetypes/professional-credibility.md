# Archetype: professional-credibility (konsultan / notaris / arsitek — credentialed practice)

## matches

- konsultan, notaris, pengacara, arsitek, akuntan publik, perencana keuangan
- any practice where credentials + track record gate every engagement

## recommended_sections

- Credentials + licenses — the specific degrees, bar memberships, or certifications that legally authorize the practice; this is the headline trust signal.
- Services scope — what the professional actually handles, bounded (e.g. "akta tanah + pendirian PT", not "segala urusan hukum").
- Track record / case highlights — selected, anonymized matters that prove domain experience without naming clients.
- Consult CTA — the engagement starts as a consultation, not a checkout.

## avoid_sections

- Fabricated guarantees — "Pasti Menang" or "100% Berhasil" is both untrue and a red flag for licensed professions.
- Testimoni carousel with photos — client confidentiality makes attributed testimonials risky; favor anonymized case highlights.
- Discount / promo banners — credibility practices do not run flash sales.

## page_count

- landing: one page. `marketing_site` only when practice areas (e.g. litigasi vs. korporat) each warrant a detail page.

## cta_logic

- Primary: "Konsultasi" or "Janji temu" with a brief intake (name + matter type). Secondary: "Unduh profil" only when a formal profile PDF (CV / firm profile) is a real asset.

## visual_hooks

- Credential marks (license number, bar ID, certification badge) visible above the fold, not in a footer.
- Case highlight cards with outcome + practice area, no client names.
- A restrained, document-like palette — trust here reads as formal, not as a consumer brand.

## example_structure

Header (name + license mark) → Credentials + licenses → Services scope → Case highlights → Consult CTA. Depart when justified — a notaris may add a fees/jurisdiction table when fee transparency is a real selling point.
