# Archetype: education-course (kursus / bimbel / workshop — learning program)

## matches

- kursus, bimbingan belajar, workshop, pelatihan, les privat, bootcamp
- any business whose product is a structured learning program

## recommended_sections

- Curriculum — the module-by-module or week-by-week outline; the program IS the product, not a teaser.
- Schedule + duration — when cohorts start, how long they run, and time commitment; the buyer plans around this.
- Instructor credibility — named teachers with their background, not a generic "tim profesional".
- Enroll CTA — the path to register, with fee + seat info visible.

## avoid_sections

- Vague outcome promises — "Pasti Lulus" or "Berhasil dalam 30 Hari" reads as fabricated guarantee.
- Generic hero tagline — "Belajar Jadi Menyenangkan" says nothing about the actual program.
- Long about section — the curriculum and instructors are the trust signals, not the founder's story.

## page_count

- landing: one page. `marketing_site` only when multiple programs (e.g. level dasar / lanjutan) each need a detail page.

## cta_logic

- Primary: "Daftar" opening the enrollment path. Secondary: "Konsultasi via WA" only when the program needs placement or pre-screening before enrollment.

## visual_hooks

- Curriculum timeline (weeks 1-N) as a horizontal or vertical track, not a feature grid.
- Instructor cards with credential tags, not anonymous avatars.
- A "next cohort starts" date badge near the CTA, not buried in body copy.

## example_structure

Header (name + next cohort date) → Curriculum timeline (module + duration) → Instructors → Schedule + fee → Enroll CTA ("Daftar"). Depart when justified — a workshop may swap the timeline for a one-day agenda block.
