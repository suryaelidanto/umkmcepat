# Archetype: retail-grocery (toko kelontong / sembako — essentials store)

## matches

- toko kelontong, sembako, warung, depot air, toko bangunan kecil
- any retail selling everyday essentials with a long item list

## recommended_sections

- Essentials list — the headline is what's available, not a brand story. Group by kategori (sembako, minuman, rumah tangga).
- Hours + location — the customer walks in; both must be visible above the fold.
- Payment + delivery info — tunai / QRIS / ojek pengiriman; the operational facts the buyer needs.
- Contact / restock ask — WA for "apa ada X?" is the real transaction, not a buy-now button.

## avoid_sections

- Product cards grid — 50+ small items make a card grid unreadable; a list wins.
- E-commerce buy-now flow — no cart, no checkout; the order happens over WA or in person.
- Hero brand tagline — "Solusi Kebutuhan Keluarga" is filler; the stock list is the value.

## page_count

- landing: one page, always. No `marketing_site`; nothing justifies a second page.

## cta_logic

- Primary: "Tanya via WA" (restock / price check). Secondary: none by default — a map CTA only if foot traffic is the main channel.

## visual_hooks

- List-first layout: kategori → item → harga, in a scannable column.
- Hours + address block sticky or top-of-page, not buried.
- Photo of the storefront, not a stock gradient — customers need to recognize the shop.

## example_structure

Header (name + hours + address) → Kategori list (expandable or grouped) → Payment + delivery info → WA restock CTA → Storefront photo + map. Depart when justified — a depot air may swap the list for a single product + delivery area.
